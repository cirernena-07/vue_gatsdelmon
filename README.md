# Gats del Món

Aplicació web desenvolupada amb Vue i Firebase per descobrir diferents races de gats i les seves curiositats.

## Tecnologies utilitzades

- Vue 3
- Vue Router
- Firebase Hosting
- Firestore Database
- CSS

## Funcionalitats

- Visualització de diferents races de gats.
- Navegació entre pàgines amb Vue Router.
- Obtenció de dades des de Firestore.
- Desplegament amb Firebase Hosting.
